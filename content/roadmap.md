# Roadmap

This page should describe a sequence of integrated demonstrations, each one de-risking the next scale step.

Suggested structure:

1. Integrated module (energy + backgrounds + topology + stability).  
2. Multi-module system test (services, calibration, uptime model).  
3. Pilot-scale deployment (realistic operations and QA).  
4. Full-scale build (procurement, logistics, schedule, commissioning).
